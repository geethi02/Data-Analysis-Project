📊 ONLINE COURSE COST ESTIMATION
***********************************

This project focuses on analyzing and estimating the optimal pricing of online courses using a data-driven approach. It combines market research, survey analysis, dashboard visualization, and machine learning to identify key pricing factors and predict the best course cost.

Tools: Python, Pandas, NumPy, Power BI / Tableau, Scikit-learn

Conducted a comprehensive literature review to understand current trends and pricing strategies in the online education market. Defined structured criteria for selecting and evaluating online courses for cost estimation. Designed and conducted an online survey to identify key features influencing course pricing such as duration, content quality, certification, and platform. Performed data cleaning, preprocessing, and analysis to identify relationships between course features and pricing. Created three interactive dashboards: Student Dashboard – focuses on learner preferences and expectations Professional Dashboard – highlights industry-oriented needs and features Common Dashboard – presents overall trends and comparisons Built a machine learning model to predict the optimal course price based on selected features.
